# 小红书保存选项与快捷指令

服务端默认只保存正文。保存图片与 OCR 是两个独立开关：

| 菜单选项 | save_images | enable_ocr |
|---|---|---|
| 只保存正文（默认） | false | false |
| 正文＋图片文字 | false | true |
| 正文＋图片 | true | false |
| 正文＋图片＋图片文字 | true | true |

OCR 关闭时不调用 OCR；保存图片关闭时不上传图片。OCR 单独开启会临时下载图片识别，生成的笔记只含文字。没有文字的图片不会生成空的 OCR 段落。已上传的旧图片不会删除。

## 修改 iOS 快捷指令

1. 保留已有的“接收共享输入／输入为空则获取剪贴板”及 URL 提取步骤。
2. 在“获取 URL 内容”之前加入“从菜单中选取”，提示“保存哪些内容？”，添加上表四项。
3. 在菜单的四个分支中各建立一个“字典”，字段名为 `save_images` 和 `enable_ocr`。**两项的类型都选“布尔值”**，按表设置是／否。
4. 每个分支都用“设定变量”将字典存为同一个变量 `保存选项`。
5. 菜单结束后，分别用“获取字典值”从 `保存选项` 读取这两项，并设置变量 `保存图片`、`识别文字`。
6. 在现有“获取 URL 内容”操作中保持 POST、请求体 JSON 及原有 url/title/original_url 字段，添加 `save_images` 与 `enable_ocr` 两个字段，类型为“布尔值”，值分别插入 `保存图片`、`识别文字`。
7. 读取响应的 `status` 和 `message`；显示 `message`。`status=error` 表示未保存成功，`status=ok` 表示已写入 OSS。

如某版本的“获取 URL 内容”无法把变量填入布尔字段，可在每个菜单分支直接调用 POST，两个布尔值在该分支中固定按表设置。

菜单中“默认”指默认行为，不是自动跳过菜单。若希望常用入口完全不用选择，可复制成两个快捷指令：日常版不加菜单、两个字段固定 false；可选版保留上述菜单。

## 请求示例：只提取文字

```json
{
  "url": "https://xhslink.cn/o/example",
  "save_images": false,
  "enable_ocr": true
}
```

两个字段缺省均为 false；字符串 `"false"`、数字 `0/1` 会被拒绝，避免误上传。新开关当前仅作用于小红书图文；视频仍执行音频转写流程。
