# 小红书快捷指令：两个保存选项

服务端默认仅保存正文，快捷指令只提供两个菜单选项：

| 菜单选项 | save_images | enable_ocr |
|---|---|---|
| 1️⃣ 仅保存正文（默认） | false | false |
| 2️⃣ 保存图片并提取文字 | true | true |

## 修改 iOS 快捷指令

1. 保留已有的“接收共享输入／输入为空则获取剪贴板”及 URL 提取步骤。
2. 在“获取 URL 内容”之前加入“从菜单中选取”，提示“保存方式”，只添加上述两个选项。
3. 在两个分支中各建立一个“字典”，字段名为 `save_images` 和 `enable_ocr`。两项的类型都选“布尔值”：第一项均为否，第二项均为是。
4. 每个分支都用“设定变量”将字典存为同一个变量 `保存选项`。
5. 菜单结束后，分别用“获取字典值”从 `保存选项` 读取这两项，并设置变量 `保存图片`、`识别文字`。
6. 现有“获取 URL 内容”保持 POST、请求体 JSON 及原来的 url/title/original_url 字段，添加 `save_images` 与 `enable_ocr` 两个布尔字段，值分别插入 `保存图片`、`识别文字`。
7. 读取响应的 `status` 和 `message`，显示 `message`。`ok` 表示已写入 OSS，`error` 表示未保存成功。

若某版本无法把变量填入布尔字段，可在两个菜单分支直接配置 POST，两个布尔值在每个分支中固定设置。

“默认”指接口省略参数时的行为，不会自动跳过快捷指令菜单。

## 请求示例

仅保存正文：

```json
{
  "url": "https://xhslink.cn/o/example",
  "save_images": false,
  "enable_ocr": false
}
```

保存图片并提取文字：

```json
{
  "url": "https://xhslink.cn/o/example",
  "save_images": true,
  "enable_ocr": true
}
```

两个字段类型必须为 JSON 布尔值，不能使用字符串 `"false"` 或数字 0/1。
照片未识别到文字时，只保存图片，不生成空 OCR 段落。
开关作用于小红书图文；视频仍执行音频转写流程。
